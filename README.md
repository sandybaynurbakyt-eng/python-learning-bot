# Python Learning Telegram Bot

## Описание проекта

Telegram бот для изучения Python.

Бот позволяет:
- проходить уроки;
- отвечать на тесты;
- получать XP;
- использовать AI помощника;
- отслеживать прогресс.

---

## Используемые технологии

- Python
- pyTelegramBotAPI
- Groq API
- SQLite

---

## Установка

**pip install -r requirements.txt**

---

## Запуск

**python main.py**

---

## Основные функции

- Уроки Python
- Тестирование
- XP система
- AI ответы
- Прогресс пользователя
- Хранение данных
