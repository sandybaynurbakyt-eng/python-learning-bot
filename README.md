# Python Learning Telegram Bot 🚀

## 1. Название проекта
**Python Learning Telegram Bot** — интерактивный игровой чат-бот в Telegram для эффективного и кастомизированного изучения базовых концепций программирования на языке Python.



## 2. Описание проекта
Данный проект представляет собой программное приложение, разработанное на языке Python, которое выполняет роль персонального ментора по программированию. Бот совмещает в себе элементы интерактивного учебника, автоматизированной системы тестирования и ИИ-помощника.

**Основные возможности и логика работы:**
* **Интерактивные лекции:** Теоретический материал разбит на последовательные модули (Переменные, Вывод данных `print()`, Условные конструкции `if`).
* **Пошаговые тесты:** После каждого урока пользователю предлагается закрепить знания через систему тестирования с интерактивными кнопками. Внедрена защита от случайного ввода сторонних команд во время прохождения теста.
* **Геймификация и уровни:** За успешное завершение тестов пользователю начисляются очки опыта (+20 XP). На основе XP динамически рассчитывается текущий ранг студента: `Beginner 🐣` -> `Junior 🧑‍💻` -> `Python Master 🚀`.
* **Интеграция с ИИ (LLaMA 3.3):** Пользователь может в любой момент задать боту технический вопрос в свободной форме с помощью команды `/ask`, на который нейросеть сгенерирует простой и понятный ответ.
* **Сохранение данных (Персистентность):** Прогресс уроков и очки опыта автоматически записываются в базу данных SQLite. Данные не сбрасываются и не теряются при перезапуске сервера или скрипта бота.

---

## 3. Используемые технологии
При разработке чат-бота использовались следующие программные инструменты и библиотеки:
* **Язык программирования:** `Python 3.10+`
* **Библиотека Telegram Bot API:** `pyTelegramBotAPI` (`telebot`) — для создания интерфейса и обработки сообщений.
* **Интеграция с ИИ-моделями:** `groq` — официальный SDK для обращения к языковой модели `llama-3.3-70b-versatile`.
* **База данных:** `sqlite3` — встроенный движок для надежного хранения информации пользователей и истории их прогресса.
* **Управление конфигурацией:** `python-dotenv` — для безопасного хранения конфиденциальных токенов и API-ключей в изолированном файле `.env`.



## 4. Инструкция по установке
Для развертывания проекта на локальном компьютере выполните следующие шаги:

1. Убедитесь, что на вашем компьютере установлен Python версии 3.10 или выше.
2. Скачайте или клонируйте исходный код проекта в отдельную рабочую директорию.
3. Откройте терминал/командную строку в папке проекта и установите все необходимые зависимости одной командой:
   ```bash
   pip install -r requirements.txt

  5. Инструкция по запуску
В корневой директории проекта найдите или создайте файл с именем .env (обратите внимание, что файл начинается с точки и не имеет расширения .py).

Заполните его вашими конфигурационными ключами в следующем формате (без пробелов вокруг знака =)
Запустите бота, выполнив команду в терминале:python main.py
В консоли должно появиться сообщение Bot started..., означающее, что бот успешно запущен и готов к обработке запросов.


6. Примеры работы чат-бота
Взаимодействие с ботом строится на командах и кнопках текстового меню:

/start — инициализация пользователя, автоматическое создание записи в БД bot.db с нулевым прогрессом (если пользователя там еще нет) и вывод приветственного сообщения с клавиатурой.

Кнопка 📚 Урок — бот проверяет прогресс пользователя в SQLite и присылает текст соответствующей лекции.

Кнопка ▶ Тест — запускает процесс проверки знаний по текущей теме. Бот генерирует кнопки с вариантами ответов.

Кнопка 🏆 XP — отображает текущее количество набранных очков опыта и динамическое звание.

Кнопка 📊 Прогресс — рассчитывает процент выполнения курса в зависимости от индекса пройденных уроков.

Команда /ask <ваш вопрос> — отправляет текстовый запрос пользователя в LLM Groq и возвращает развернутый ответ от «ИИ-учителя».
