Архитектура и стек разработки
03 / 07

Выбранные технологии проекта:

  • Язык Python 3.10 — стандарт разработки современных серверных скриптов.
  • pyTelegramBotAPI (telebot) — библиотека для быстрого конфигурирования событий и кнопок.
  • СУБД SQLite3 — встроенное легковесное хранилище, не требующее внешнего администрирования.
  • Groq Cloud API (Llama 3.3) — высокоскоростной ИИ-движок для развернутых ответов по коду.

Проектирование Базы Данных
04 / 07

Для реализации сохранения прогресса без риска потери данных при сбоях спроектирована и внедрена реляционная СУБД SQLite3.

Создана таблица users, которая хранит текущие состояния студентов:

Поле Тип данных Описание
id INTEGER PRIMARY KEY Уникальный Telegram ID пользователя
xp INTEGER Количество набранного опыта (очков)
progress INTEGER Индекс текущей лекции в списке курса 
# Инициализация структуры базы данных
conn = sqlite3.connect("bot.db")
cursor = conn.cursor()

cursor.execute("""
CREATE TABLE IF NOT EXISTS users(
    id INTEGER PRIMARY KEY,
    xp INTEGER,
    progress INTEGER
)
""")
conn.commit()
Учебный план и логика званий
05 / 07

3 базовых модуля курса:

  • Переменные (Variables): Объявление, присваивание и типы данных (int, string, bool).
  • Вывод (Print): Вывод текстовой информации и значений переменных на экран.
  • Условия (If): Базовая условная конструкция, логика истинности (True/False).

Система званий на основе опыта (XP):

< 50 XP: Beginner 🐣 50 - 149 XP: Junior 🧑‍💻 >= 150 XP: Python Master 🚀 
# Реализация динамической смены ранга пользователя
def level(points):
    if points < 50:
        return "Beginner 🐣"
    elif points < 150:
        return "Junior 🧑‍💻"
    else:
        return "Python Master 🚀"
